# Copy Rewrite Prompt (Niche-Specific)

Use this when you want to rewrite only the copy for a specific niche — without changing stats, testimonials, or other content.

Attach: hero.ts, features.ts, cta.ts

---

I have a SaaS landing page template and I need to rewrite the copy to speak directly to a specific niche.

My niche: [e.g., "HR teams at mid-market SaaS companies", "solo founders building developer tools"]

My product: [PRODUCT NAME] — [ONE SENTENCE DESCRIPTION]

Please rewrite the following copy elements only:

1. hero.ts — badge, headline, headlineHighlight, body, ctaPrimary.label, ctaSecondary.label, disclaimer
2. features.ts — all feature titles and descriptions
3. cta.ts — headline and body

Rules:
- Use the niche's own language — the words they use in Slack, Reddit, job postings
- Avoid generic SaaS buzzwords: "seamless", "robust", "powerful", "next-generation"
- Each feature description should name a specific pain it removes, not a capability it adds
- The CTA headline should be a statement of relief, not a call to action
- Keep all TypeScript structure identical — only change string values

Output complete, ready-to-paste file content for each of the three files.
